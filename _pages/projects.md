## Project Presentation Tip

For projects that you are allowed to discuss publicly, add:

- Your exact responsibility
- Architecture diagram
- APIs/services you designed
- Performance or reliability improvements
- Security considerations
- Technologies used
- GitHub repository or public demo

Avoid publishing confidential banking architecture, credentials, customer data, internal endpoints, or proprietary implementation details.
